# Windows fork development

- Scope: unofficial experimental WindowsApps Codex usage-card helper; retain upstream MIT and attribution.
- Test: `node --test tests/windows.test.cjs` from this directory.
- Build: `./build-auto-helper.ps1`; package: `./package.ps1`. Outputs under ignored artifacts/ only.
- Stack: Node.js 24+, C#/.NET Framework 4, Windows PowerShell 5.1, loopback CDP 39222.
- src/ contains native code; lib/ contains usage and activation; docs/ contains user-facing safety limits.
- Never commit binaries, shortcuts, runtime/, config.json or personal paths/credentials.
- Build must not install or enable anything; shortcuts are generated by a separate user action under 管理工具/.
- Never overwrite live binaries, close the user's current Codex during deployment, force-kill, expose CDP or modify the installed app. Keep baseline, age, foreground, window-count and cooldown guards.
- Do not delete active locks, current status or cooldown records to force attachment.
- 2026-11-02: current input-allowed policy verified on one PC for original-icon launch and Windows reboot/login startup, handoff, visible rings and refreshing quota; not broadly compatible or stable.
- User explicitly authorized startup handoff despite keyboard/mouse input, accepting interruption of newly started work. Input-based skip/cancel is removed; other guards remain. Do not claim stability or broad compatibility.
- Fresh-process age limit is 30s. Keep README and docs/AUTO-ASSISTANT.md aligned with this policy. Publish v0.1.1-windows-preview.1 without replacing the old v0.1.0 assets.
- Production directory is a deployment mirror, not a second source repository. Sync current source/docs without overwriting live binaries or clearing runtime state. Temporary build cleanup requires a separate post-report confirmation.
